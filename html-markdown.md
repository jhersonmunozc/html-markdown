# Introducción a las Expresiones Regulares
Las expresiones regulares, también conocidas como regex, son una herramienta poderosa para buscar, validar y transformar texto. Se utilizan en una amplia variedad de lenguajes de programación, como Python, JavaScript y Java.

## Usos Comunes
- Validar formatos de correo electrónico.
- Buscar patrones específicos en grandes volúmenes de texto.
- Reemplazar palabras o frases automáticamente.

## Ejemplo en Python
**En Python, el módulo `re` permite trabajar fácilmente con expresiones regulares. Por ejemplo:**

import re texto = "Hola mundo" resultado = re.sub(r"mundo", "Python", texto) print(resultado)

### Conclusión
